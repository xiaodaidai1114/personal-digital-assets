# 个人数字资产

仅 Android 的个人数字资产管理 App：统一管理邮箱 / AI 订阅、API Key、日常密码、个人物品与账单；资产之间以带类型的边建立关联，最终以图谱呈现。

## 当前状态（MVP 迭代一）

- 主密码保险库：创建 / 解锁 / 锁定；PBKDF2 派生密钥 + AES-256-GCM 加密（Argon2id 已列入计划）
- 资产管理：9 种类型、标签、类型筛选、敏感内容加密保存与查看
- 关系模型与内存仓库，内置全虚构演示数据
- 数据当前仅驻内存，重启即清空；SQLCipher 持久化在下一迭代

## 安全说明

- 本仓库不存放任何真实个人数据，演示数据全部虚构
- 敏感字段加密后保存，明文不落盘、不写日志

## 开发环境

Flutter SDK 位于 `C:\dev\flutter`，依赖走国内镜像，具体命令见 `AGENTS.md`。
