# 页面规格 · 青穹资产云（Airy Vault）

产品契约见 [DESIGN.md](DESIGN.md)，视觉锁点见 [design-system.md](design-system.md)。本文件记录当前 Android 前端的页面契约；新增 UI 必须先通过这些检查。

## 信息架构

- 无底栏。首页 AppBar：标题「青穹资产云」，非多选态右侧为计数文本 + 锁（Panic，点击即锁、无任何确认）+ 设置齿轮；多选态标题为「已选 N 项」。
- 桌面宽屏（≥1024）保留三栏：集合 / 列表 / 详情；集合栏承担类型与标签筛选，移动端筛选一律走命令面板。
- 浏览器仅用于预览 Android UI。Web 视口 ≥760px 时以 430px 手机画布居中显示。

## 首页（倾倒 + 检索 + 列表）

- 置顶第一模块是倾倒口：多行输入框「粘贴倾倒：SSH 指令 / .env / JSON 凭证」，右侧封缄入库按钮随内容启停。
- 倾倒流程：粘贴 → 纯端侧解析（lib/data/dump_parser.dart）→ 草稿核对 sheet（类型识别、标题可改、字段清单、敏感内容封缄提示）→ 封缄入库。解析失败提示手动新增，不猜半成品。
- 倾倒口下方是面板入口 pill「检索资产、字段、标签…」与计数行「当前 N 项 · 30 天临期 N 项」；点击唤醒命令面板。
- 命令面板为 topCenter 对话框：极模糊匹配 标题/标签/类型/自定义字段（含字段值，暗数据不出暗区），标题命中高亮、按相关度排序；选中直达详情；无匹配显示空态；宽屏限宽 560。
- 资产列表为 56dp 高密度行：线框类型徽章、名称、中段折叠元信息（smartTruncate 保留首尾）、右齐金额、1px 分隔线；置顶用行左 2px 线表达。
- 多选用 GFCheckbox；批量操作（置顶/删除/打标签）只在多选态出现。骨架屏走 GFShimmer。新增入口为 skin.primary 的方形 FAB。
- 新增先选类型；类型选择为网格并展示字段提示；服务器类型字段为 host/port/user/key。

## 到期与扣款清单（原哨所）

- 不是 tab、首页无哨所条：入口藏于设置「提醒」，页面独立存在。
- 先给未来 30 天清单，再给月度分布；每行说明原因与对象并提供主动作；无事项只显示状态良好，不制造健康分。
- 后台到期提醒服务（notifications）不依赖页面存在。

## 星图（已退役）

- 图谱代码、webview 依赖与资产已全部删除；依赖关系改为详情页「上下游依赖」列表表达。

## 详情与编辑

- 详情按 头卡（类型+标题+标签）、上下文主动作、字段表、封缄、备注时间线、图片、上下游依赖 组织；卡片容器为 GFCard 皮肤适配（_DetailCard）。
- 上下文主动作按类型出现：服务器 = 复制 SSH 指令（按字段拼装）；带封缄资产 = 解锁并复制（8 秒倒计时自动清空剪贴板）。
- 上下游依赖列表：每行标注 上游/下游 方向 + 边类型 + 对方资产，可移除、可添加。
- 删除确认展示爆炸半径：波及依赖数 + 受影响资产清单（最多列 5 项）。
- 封缄卡保留虚线边框 + 8 秒自动收回；复制提示剪贴板风险。
- 编辑先选类型，再展示类型模板；完整密码、Key、卡号只能进入敏感内容加密保存；敏感字段留空保存表示保留原密文。

## 解锁与设置

- 解锁为居中卡片 + GFButton（skin.primary，blockButton）；busy 文案「正在解锁保险库」；首启警告「主密码无法找回。丢失后只能重置保险库。」
- 设置分区：外观（亮色/暗色/跟随系统 三选）、安全（立即锁定 GFButton outline DANGER、自动锁定、生物识别 GFToggle）、提醒（到期与扣款清单入口）、数据（加密备份导出/恢复）、关于（版本「青穹资产云」）。
- 外观为原生 ThemeMode 双主题，暗色不是滤镜；Panic 锁与立即锁定均无确认弹窗。
- 破坏性操作弹 12dp 对话框，删除按钮右置并使用 `danger`。
