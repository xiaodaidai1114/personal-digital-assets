# 页面规格 · 纸墨加密账册

完整视觉与交互原则见 [DESIGN.md](DESIGN.md)。本文件记录当前 Android 前端的页面契约；新增 UI 必须先通过这些检查。

## 信息架构

底栏四项：保险库、哨所、星图、设置。新增入口只属于保险库，使用墨色方形加号，不是紫色胶囊 FAB。

浏览器仅用于预览 Android UI。Web 视口 ≥760px 时以 430px 手机画布居中显示；桌面三栏不在当前产品范围内。

## 保险库

- 首屏第一模块是哨所：逾期、7 日内到期、敏感为空、重复标题、孤儿节点。
- 搜索常驻；筛选打开底部抽屉，支持类型、标签包含/排除、状态、排序，并实时显示结果数。
- 资产列表为 56dp 高密度行：线框类型徽章、名称、元信息、右齐金额、1px 分隔线。
- 置顶用行左 2px 墨线表达；批量选择才显示置顶与删除操作。
- 新增先选类型；类型选择为 3×3 网格并展示字段提示。

## 哨所

- 主问题是“有什么必须处理”，先给未来 30 天清单，再给月度分布。
- 每行必须说明原因与对象，并提供一个主动作。
- 无事项时只显示“保险库状态良好”，不制造健康分。
- 月格选中用 `paper2 + ink`，今天用 `mark` 边，不使用彩色圆底。

## 星图

- 页面强制夜纸，不随系统深浅模式切换。
- 节点为夜墨空心圆、圆角方、菱形；边为 1px 夜墨透明线。
- 搜索自动保留一跳邻域；点选节点高亮一跳，非邻域降至 18%。
- 图谱兜底必须仍能读取节点与边，不允许只显示失败插画。

## 详情与编辑

- 详情按字段表、封缄、局部图、关系行组织；局部图高度 200。
- 封缄卡使用 `sheet + 8dp + 虚线边框`；复制后 8 秒收回并提示剪贴板风险。
- 编辑先选类型，再展示类型模板；完整密码、Key、卡号只能进入敏感内容加密保存。
- 敏感字段留空保存表示保留原密文；解密失败只在封缄区内给出“无法解密”与重新解锁入口。

## 解锁与设置

- 解锁是纸面整页与居中 `sheet`；busy 文案为“正在解锁保险库”。
- 首启警告使用纸槽表达“主密码无法找回。丢失后只能重置保险库。”
- 设置负责外观模式、锁、自动锁定、生物识别、加密备份、恢复与版本。
- 外观模式提供「早晨 / 晚上」，两者都保持白底黑字；晚上仅将纸面调为暖白。
- 破坏性操作必须弹 12dp 对话框，删除或锁定按钮右置并使用 `danger`。
