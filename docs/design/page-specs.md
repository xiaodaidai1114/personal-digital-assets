# 页面规格 · Digital Asset OS

依据《design-system.md》。每页按布局、状态、交互、无障碍四部分定义。

## 1. 解锁页 UnlockScreen

```
┌──────────────────────┐
│  gradient/light 整屏 │
│  （浅渐变，深字）     │
│  ┌────────────────┐  │
│  │ 盾形封缄图标    │  │
│  │ 创建主密码/解锁 │  │
│  │ 密码框 ×1~2    │  │
│  │ [创建/解锁]     │  │
│  └────────────────┘  │
│  底部安全提示（浅紫） │
└──────────────────────┘
```

| 状态 | 规格 |
|---|---|
| normal·首启 | 标题"创建主密码"；密码 + 确认两框；下方 warning tint 提示卡"主密码无法找回，丢失即数据重置" |
| normal·日常 | 标题"解锁保险库"；单密码框；（未来）生物识别按钮 |
| loading | 按钮 → 进度条 + 文案"正在生成密钥（210,000 次迭代加固）" |
| error | 密码框下方 danger 文案"主密码错误"；连续 5 次追加冷静说明"数据已加密保护，可稍后再试" |
| success | `motion/slow` 渐变展开转场进入主界面 |

校验：主密码 ≥8 位；两次不一致框下提示。键盘弹出时卡片上移不被遮挡。

## 2. 资产列表 AssetListScreen（首页）

```
┌──────────────────────┐
│ gradient/hero 圆角区  │
│ 我的资产    统计卡×3  │ ← 横滑：总数/本月账单/临期提醒
├──────────────────────┤
│ chips：全部 邮箱 订阅…│
│ ┌──────────────────┐ │
│ │徽章 标题     金额│ │
│ │     类型 · 标签   │ │
│ └──────────────────┘ │
│        …             │
│            [＋ 新增] │
└──────────────────────┘
```

| 状态 | 规格 |
|---|---|
| normal | 资产卡列表；账单卡右列金额（bill deep、tabular、700） |
| empty·全库 | 渐变晕 + `inventory_2` 线性图标 + "还没有资产" + 按钮"新增第一条资产" |
| empty·筛选 | "该类型暂无资产" + 按钮"清除筛选" |
| loading | 骨架卡 ×5（surface 底 + 微光扫过） |
| error | "读取资产失败" + 重试按钮（接数据库后启用） |

交互：点卡片 → 详情；FAB 渐变底白字"新增"；（未来）长按多选、拖动排序。

## 3. 资产详情 AssetDetailScreen

```
┌──────────────────────┐
│ [64dp 大徽章]  标题   │
│ 标签 chips           │
│ ┌ 字段卡 ──────────┐ │
│ │ key            v │ │
│ └──────────────────┘ │
│ ┌ 封缄敏感卡 ──────┐ │
│ │ 锒 敏感内容 [显示]│ │
│ └──────────────────┘ │
│ 关联                  │
│ 关系行…  [添加关联]   │
└──────────────────────┘
```

| 状态 | 规格 |
|---|---|
| normal | 字段 key-value 列表；关系行显示方向 |
| empty·无关联 | "资产之间还没有关联" + 按钮"添加关联"（未来迭代） |
| loading | 居中转圈 |
| error·解密失败 | 封缄卡内 danger 文案"无法解密：保险库状态异常" + "重新解锁"入口 |
| error·不存在 | "资产不存在或已删除"，自动返回列表 |

操作：顶部编辑 / 删除（danger）；删除弹确认对话框，文案明确"相关关联也会一并移除"。

## 4. 资产编辑 AssetEditScreen

```
┌──────────────────────┐
│ 类型（3×3 徽章网格）  │
│ ◉邮箱 ○订阅 ○Key …   │
│ 名称 [________]      │
│ 标签 [________]      │
│ ┌ 封缄输入卡 ──────┐ │
│ │ 已加密 · [修改]   │ │
│ └──────────────────┘ │
│ [      保存        ] │
└──────────────────────┘
```

- 类型选择用徽章网格替代下拉：每格 = 类型徽章 + 中文名，选中加 deep 描边 + tint 底。
- 编辑既有资产时敏感内容默认显示"已加密"，点"修改"才展开明文输入（留空保存 = 保持原密文）。
- 校验：名称必填（框下"请填写名称"）；类型必选（默认密码）。
- 状态：保存中按钮进度；失败 snackbar + 重试。

## 5. 图谱页 GraphScreen

```
┌──────────────────────┐
│ gradient/nebula 整屏 │
│ frosted 深色 chips   │
│      ○───○           │
│   ╱      ╲           │
│  ●───────○  拖拽/缩放 │
│ ┌ 节点抽屉 ─────────┐ │
│ │ 徽章 标题 [查看]   │ │
│ └──────────────────┘ │
└──────────────────────┘
```

- 页面级固定夜底（不随系统深浅切换，产品定义：图谱=夜）。
- 节点：24dp 类型色点 + 白标签（`graph/node`，微描边保证可读）；边：`graph/edge`，选中边高亮为类型 light 色。
- 交互：拖拽/缩放（WebView G6）；点节点 → 底部抽屉（资产摘要 + 查看详情）。

| 状态 | 规格 |
|---|---|
| normal | 关系网络，节点渐次点亮入场（≤600ms） |
| empty·无资产 | 星云底 + "先添加资产，星图会在这里点亮" + 按钮"去新增" |
| empty·无关系 | "资产之间还没有关联" + 按钮"去资产页添加关联" |
| loading | 星点渐次点亮动画（非转圈） |
| error | WebView 加载失败 → 原生兜底：列表形式展示节点+边 + "重试图谱" |

## 6. 设置页 SettingsScreen

分组白卡（未来项标"规划中"置灰）：

- **安全**：立即锁定（danger 描边按钮）、自动锁定时长（规划中）、生物识别解锁（规划中）
- **数据**：加密备份导出（规划中；导出中显示进度、成功 toast、失败重试）
- **关于**：当前版本、路线图阶段

状态：normal / 锁定确认弹窗 / 备份中进度 / 备份失败重试。

## 7. 全局文案原则

CTA 用同一动词贯穿全流程：保存、删除、显示、隐藏、锁定、解锁、重试。错误文案 = 说清发生了什么 + 怎么办；空状态 = 一句主文案 + 一个行动按钮；不卖弄情绪。
