# DESIGN.md · 青穹资产云（Airy Vault）

私人数字资产操作系统。
这份文件是视觉与交互的唯一依据。实现时先读原则和反模式，再查 token。

产品不是密码管理器皮肤，不是订阅看板，也不是科幻星图。
它是一本加密账册：白天是纸和墨，夜里是关了灯的纸。

---

## 1. Brand

### 一句话

打开先看见今天要办的事，三秒内能找到任何一条资产，并看清它和谁相连。

### 性格

克制、可扫描、可信任。美来自对齐和密度，不来自渐变。

对标结构，不抄皮肤：

- Things 3：95% 中性，色只表示语义
- Apple Passwords：大标题 + 集合 + 列表 + 详情三栏
- Mercury：金额像财务报表
- Linear：静 chrome；禁止项比色值更重要

### 三个任务（导航按此命名）

| 任务 | 界面 | 主问题 |
|---|---|---|
| 找 | 保险库 | 东西在哪 |
| 办 | 哨所 | 今天必须处理什么 |
| 懂 | 星图 | 它和谁相连 |

设置只负责锁、备份、版本。新增不是第五个 Tab，是保险库里的动作。

### 心智模型

- 保险库 = 容器与保护
- 哨所 = 不可见风险变成清单（Watchtower）
- 星图 = 巡视工具；日常工作在详情的一跳邻域
- 封缄 = 明文默认不在场

## 2. Color

印刷色，不是品牌海报。一屏里色彩几乎不发言。

| Token | Value | Use |
|---|---|---|
| `paper` | `#F6F2EA` | 画布 |
| `paper-2` | `#EFEBE3` | 输入槽、选中行、骨架 |
| `sheet` | `#FBF8F1` | 模态、抽屉，比纸白一档 |
| `ink` | `#1C1B17` | 标题、正文、线框图标、主按钮 |
| `ink-2` | `#6A675E` | 元信息，≥4.5:1 |
| `ink-3` | `#9A9588` | 仅 ≥12px 辅助 |
| `rule` | `#E6DFD2` | 细线、输入描边 |
| `mark` | `#8A4A2B` | 唯一强调：逾期、文字链、焦点环 |
| `danger` | `#8B2E2E` | 删除、解锁失败 |
| `ok` | `#3D5A45` | 成功，极少用 |
| `night-paper` | `#1A1915` | 星图画布（产品强制，不跟系统） |
| `night-sheet` | `#24221C` | 星图顶栏与底抽屉 |
| `night-ink` | `#EDE8DC` | 夜文字、空心节点 |
| `night-muted` | `#A39B8C` | 夜次要文字 |
| `night-rule` | `rgba(237,232,220,.12)` | 夜细线 |
| `night-dim` | `18%` opacity | 非一跳邻域 |

主按钮 = `ink` 底 + 白字。
选中集合 / chip = `paper-2` 底 + `ink` 字 + 1px `ink` 边。
危险实心按钮只用于对话框里的「删除」，右置。

### 类型色

默认关闭。类型 = 线框图标 + 文字。
星图用形状区分（圆 / 圆角方 / 菱），不用九色填。

若无障碍场景必须加色，只用 1px 针点，不得铺底。

## 3. Typography

- 中文 UI：Noto Sans SC / PingFang SC。页名可用 Noto Serif SC / 宋，**仅页名**。
- 控件、列表、表单、按钮禁止衬线。
- 金额、日期、倒计时、版本号：`tnum` + 右齐。
- 字重只要 400 / 510 / 650。不要 800 海报粗。

| Token | Size / Line / Weight | Use |
|---|---|---|
| `display` | 28 / 34 / 650 | 保险库主数字，一屏最多一处 |
| `title` | 22 / 28 / 650 | 页面名 |
| `title-sm` | 16 / 24 / 650 | 资产名、对话框标题 |
| `body` | 14 / 22 / 400 | 正文、列表次行 |
| `label` | 12 / 16 / 510 | 辅助、时间、集合计数 |
| `micro` | 11 / 14 / 510 | 图标签、徽章内 |

页名 tracking 0。展示数字 -1%。正文 0。

动态字号 1.3×：标题单行省略，次行最多两行，金额独立右列。

---

## 4. Spacing & Shape

- 基线 8。半步 4。常用 4 / 8 / 12 / 16 / 24 / 32。
- 屏边 16（手机）/ 24（桌面栏内）。
- 区块之间 24–32。行内 8。标题到下一块 8–12。
- 列表行高 56。不要用 96 大卡做默认列表。
- 圆角：**8 控件与输入，12 模态**。禁止 20+。
- 触控 ≥44，推荐 48。
- 阴影：无。层级 = `paper` 上放 `sheet`，或 1px `rule`。
- 分隔用 1px `rule`，不用粗色条。置顶用行左 2px `ink` 条，不用每行一颗星。

## 5. Layout

### 手机

底栏四项：保险库 / 哨所 / 星图 / 设置。
保险库可有墨色 ＋（方圆 8，不是紫 FAB）。

### 桌面 ≥1024

三栏，对标 Apple Passwords：

```
220          360–420        剩余
集合          列表            详情
哨所          搜索 / 分段
类型
标签
```

点列表即在右栏打开详情，不跳全屏栈。
星图、解锁、设置吃满画布。

### 密度

这是每天打开的工具。保险库中栏一眼 8–10 行。
留白给区块之间，不给每一行再套一张卡。

## 6. Components

### 顶栏

左页名 `title`。右搜索、筛选、溢出。
计数写成 `128`，副信息放名称下一行 `label` + `ink-2`。

### 主数字

中性、最多一个 `display`。
例：`¥1,284` +「本月将扣 · 3 笔 7 日内到期」。
禁止渐变英雄卡，禁止三张同等统计卡。

### 哨所条

首页第一模块，0–3 行。每行 = 原因 + 对象 + 一个主动作。
无事项：「保险库状态良好」，可进哨所看规则。
优先级：已逾期 > 7 日内到期 > 敏感为空 > 重复名称 > 孤儿节点。

### 资产行

```
[20 线框图标]  标题                         [金额或 ›]
               类型 · 标签 · 更新
```

账单/订阅才显示金额。按压：背景 `paper-2`，140ms。无跳影。
星标不常驻列表。

### 类型徽章

28 / 36 线框圆，1.5px `ink`，outlined 图标，无填色。
类型选择用 3 列网格：图标 + 类型名 + 一句字段提示。

### Chip / 集合

未选：透明 + `rule`。选中：`paper-2` + 1px `ink`。
已选条件是可删 token，删一颗不清空其余。

### 封缄

默认：虚线框 + 锁 +「已加密」+「显示」。
展开：等宽明文 +「复制」「隐藏」。8 秒收回，并提示将从剪贴板清除。
留空保存 = 保留原密文。失败只在区内报：「无法解密」+「重新解锁」。

### 关系行

「付给 / 登录于 / 运行在 / 属于」+ 对方名。
解除确认一句：关联会从双方移除。

### 局部图

详情内高度 200。当前节点略大，一跳邻居空心点 + 1px 线。
「打开星图」跳转全局并聚焦。

### 空状态

单线图标 + 一句事实 + 一个按钮。
「还没有资产」+「新增第一条」。禁止第二句抒情。

### 解锁

`paper` 整页，居中 `sheet`。主按钮 busy 文案：「正在解锁保险库」。
技术细节（迭代次数）不进按钮。
首启标题「创建主密码」，warning 表面用 `paper-2` 而不是红色恐吓：「主密码无法找回。丢失后只能重置保险库。」

### 对话框

12 圆角。破坏性操作必须对话框。删除右按钮 `danger` 实心。

### 骨架 / Toast

骨架：列表形 ×6，`paper-2` + 微光。
Toast：`ink` 底白字，单动作「重试」。

## 7. Screens

每个屏幕只回答一个主问题。

| Screen | 主问题 | 要点 |
|---|---|---|
| Unlock | 我是主人吗 | 日常单框；首启两框 + 无法找回 |
| Vault | 今天办什么，下一秒找什么 | 哨所薄条 + 可扫描行；桌面三栏 |
| Watchtower | 有什么必须处理 | 分组清单，每行一个动作；不做伪百分健康分 |
| Detail | 这一条的事实、秘密、关系 | 字段表 + 封缄 + 局部图 |
| Edit | 写对，并决定什么加密 | 先选类型；完整卡号/密码/Key 只能进封缄 |
| Graph | 选中的东西和谁相连 | 强制夜纸；默认聚焦一跳；全局是巡视 |
| Settings | 锁上、备份、版本 | 规划中置灰；立即锁定要二次确认 |
| Type picker | 这是哪一类 | 3×3 网格，选中再进表单 |
| Filter | 如何收窄 | 类型 / 标签含排除 / 状态 / 排序；实时结果数 |
| Confirm delete | 后果是什么 | 「相关关联会一并移除」 |
| Empty vault | 下一步做什么 | 一句 + 新增 |
| Empty filter | 如何回到全部 | 「没有匹配」+「清除筛选」 |

类型模板（编辑页）：

- 订阅：套餐、周期、金额、下次扣款、自动续费
- API Key：前缀、环境、到期
- 密码：用户名、网址
- 邮箱：地址、恢复邮箱
- 设备：型号、系统、序列号、保修
- 账单：金额、日期、已支付
- 银行卡：银行、后四位、有效期

未知自定义字段保存时保留。

## 8. Motion

| Token | Value | Use |
|---|---|---|
| `instant` | 80ms | 焦点环 |
| `fast` | 140ms | 按压、chip、行背景 |
| `medium` | 220ms | 抽屉、封缄 blur+opacity |
| `slow` | 360ms | 解锁进入、图谱入夜 |
| `ease` | `cubic-bezier(0.2, 0, 0, 1)` | 默认 |

解锁：白卡上移淡出，主界面从 8px 下淡入。不要整屏渐变展开。
星图：画布 360ms crossfade，节点按度数分 3 批点亮，总长 ≤500ms。
`prefers-reduced-motion: reduce` → 0ms 或仅 opacity。

## 9. Voice

短、具体、可执行。同一动词贯穿：保存、删除、显示、隐藏、锁定、解锁、重试、处理。

好：「主密码错误，还可试 4 次。」
差：「好像走错了星门。」
好：「相关关联会一并移除。」
差：「此操作可能影响宇宙结构。」

错误 = 发生了什么 + 下一步。
空状态 = 一句事实 + 一个按钮。
安全提示只说后果。

---

## 10. Accessibility

- 正文对比 ≥4.5，大号数字与图标 ≥3.0。
- 图标按钮必须有中文语义标签。
- 类型与状态禁止只靠色。
- 焦点环：2px `mark`，偏移 2px。
- Tab 顺序 = 视觉顺序。星图提供节点表 + 边表兜底。
- 触控间距 ≥8。

---

## 11. Anti-patterns

禁止：

- 青紫品牌渐变出现在日常页
- 一屏超过一个渐变容器
- 每类资产一种填色圆
- 卡片圆角 >12，按钮胶囊到失去矩形
- 用阴影制造高级感
- 把总数、临期、未关联做成三张同等大卡
- 列表行同时放星标、金额、三枚状态徽标、关系数、相对时间
- 星图靠粒子和光晕取胜
- 空状态写情绪句
- 按钮上写迭代次数
- 伪精确的 100 分安全分
- 同一产品里混用填色图标与线框图标
- 每一行再套一张大卡（卡片汤）
- 展板式标签（屏幕底下再写一遍页面名）当产品 UI

## 12. Frontend lock

实现前把这些轴锁死，不要每做一个组件再选一次：

```
radius     8 / 模态 12
shadow     none
accent     ink 主按钮；mark 仅逾期与链接
icon       outlined, 同一 stroke
type       页名可衬线；其余 Sans
money      tnum 右齐
row        56
grid       8
home       先看见要办的事，不是先看见 128
desktop    三栏
graph      夜纸 + 默认一跳
```

一致比漂亮更重要。漂亮的零件拼不出产品；同一套决定才能。
