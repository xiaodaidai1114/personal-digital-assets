# DESIGN.md · 青穹资产云（Airy Vault）

本地优先的机密数字基础设施（Local-first Digital Infrastructure & Secret Manager）。
本文件是产品交互、安全架构与视觉系统的唯一契约。

核心定位：这不是一个大众财务记账本，也不是用来存放影音网站密码的消费级玩具。它是面向开发者、创客与数字游民的高价值资产调度中心（管理 API 密钥、服务器实例、数据库凭证及核心订阅）。

## 1. 架构与安全底线（Architecture & Security）

安全不能仅停留在 UI 层的恐吓，必须深入到底层数据结构。

- **全量零知识加密（Zero-Knowledge & Full E2EE）**：不仅密码和密钥本身需要加密，资产名称、关联拓扑、标签、时间线等所有元数据（Metadata）必须同等强度加密。禁止资产存在性泄露。
- **端侧沙盒解析（Local Agent Parsing）**：数据录入依赖本地运行的轻量级解析模型或正则引擎（NER）。用户倾倒非结构化文本，系统在端侧沙盒完成结构化提取，严禁明文流经云端。
- **硬核防暴破**：底层采用高迭代的 Argon2id 密钥派生函数，通过计算资源消耗（如单次解密强制耗时 500ms+）抵御离线字典暴破。废除单纯依赖 UI 的计数器。
- **灾难恢复机制（Disaster Recovery）**：首启流程强制用户导出物理恢复密钥（Recovery Kit / Paper Key）或建立密钥分片。

## 2. 核心交互流（Core Loops）

彻底抛弃「列表找寻 → 表单填空」的过时逻辑，转为「倾倒 → 检索 → 消费」的极速闭环。

- **输入：全局倾倒口（Dropzone）**
  - 首页只保留最显眼的全局输入框。
  - 用户直接粘贴 `.env` 配置文件、SSH 登录指令、或 JSON 格式的凭证。
  - 动作：本地 Agent 解析后，弹出「草稿卡片（Draft Card）」，用户一眼核对提取出的环境、账号、密钥等字段，一键「封缄入库」。
- **检索：命令控制台（Command Palette）**
  - 废除底栏的类型和标签抽屉。核心入口为下拉或快捷键唤醒的命令面板。
  - 支持极模糊匹配。
  - 自定义字段必须全部进入本地倒排索引，消除无法检索的暗数据。
- **消费：上下文首要动作（Contextual Actions）**
  - 资产的尽头是使用。列表滑动或详情页提供基于 Type 的高亮主动作。
  - API/密码类：「解锁并复制」，UI 触发 8 秒倒计时，结束后自动清空剪贴板。
  - 服务器类：「复制 SSH 指令」，直达终端。

## 3. 动态防御与拓扑（Watchtower & Topology）

不要让用户每天像批阅奏章一样巡视系统，系统必须主动防御。

- **底层触发器（Active Triggers）**：废除作为首页薄条的静态「哨所」。哨所应作为后台的静默守护进程，当域名即将到期、或本地计算出订阅将要扣款时，通过系统级 Push 主动告警。
- **爆炸半径警告（Blast Radius）**：废除高认知负荷的图数据库「星图」及节点动画。详情页底部用清晰的「上下游依赖列表」代替。当用户尝试删除一个核心凭证时，必须弹出「爆炸半径警告」。

## 4. 视觉与排版红线（Visual & Typography）

克制不等于致盲，工具的本质是极高密度的信息传递。

- **强制支持暗黑模式（Dark Mode Required）**：面向运维和夜间应急场景，全系统必须提供深色模式（非滤镜，而是原生的 Night Theme）。
- **智能截断（Smart Truncation）**：对于高度同质化的资产，采用中段折叠或允许核心标识换行展示，确保列表扫视的精准度。
- **一键锁定（Panic Button）**：点击锁定或 App 退入后台时必须瞬间锁死，绝对禁止任何形式的二次确认弹窗。
- **动态字段与大文件隔离**：底层必须采用灵活的文档型存储。图片/附件必须实施文件系统级别的加密隔离（Encrypted File Sandbox）。

## 5. 跨端与冷启动（Cross-platform & Onboarding）

跨端流转是生死线：纯 Android 的加密库是数据孤岛。架构设计初期必须规划跨端剪贴板同步机制、或轻量级浏览器插件 API。

- **破冰状态（Onboarding）**：必须提供「一键导入 Chrome 密码」或「解析标准 .csv 凭证库」的引导操作，大幅降低用户迁移数字资产的启动摩擦力。
