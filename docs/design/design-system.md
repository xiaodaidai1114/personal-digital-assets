# 设计系统 · 纸墨加密账册

现行唯一设计依据是 [DESIGN.md](DESIGN.md)。本文件只保留实现时最常查的锁点；两者冲突时以 `DESIGN.md` 为准。

## 视觉锁点

- 日常页使用纸墨体系：`paper` 画布、`sheet` 表面、`ink` 文字与主按钮、`rule` 细线。
- 一屏最多一个主数字；列表行高 56，不用默认 96 大卡。
- 控件与输入圆角 8，对话框和底部抽屉圆角 12；禁止 20 以上圆角。
- 全部无阴影；层级靠 `paper` / `sheet` / 1px `rule` 表达。
- 类型色默认关闭；类型用线框图标、文字和星图形状表达。
- 金额、日期、倒计时、版本号使用 tabular figures 并右对齐。
- 星图强制夜纸 `#1A1915`，空心夜墨节点、1px 细线；非一跳邻域降到 18%。
- 动效：fast 140ms、medium 220ms、slow 360ms；解锁是纸面淡出而非渐变开帘。

## 色彩 Token

| Token | 值 | 用途 |
|---|---|---|
| `paper` | `#F6F2EA` | 日常画布 |
| `paper2` | `#EFEBE3` | 输入槽、选中集合、骨架 |
| `sheet` | `#FBF8F1` | 模态、抽屉、卡片表面 |
| `ink` | `#1C1B17` | 标题、正文、线框、主按钮 |
| `ink2` | `#6A675E` | 元信息 |
| `ink3` | `#9A9588` | 仅 ≥12px 辅助信息 |
| `rule` | `#E6DFD2` | 细线与输入描边 |
| `mark` | `#8A4A2B` | 逾期、链接、焦点 |
| `danger` | `#8B2E2E` | 删除与解锁失败 |
| `ok` | `#3D5A45` | 成功，极少使用 |
| `nightBackground` | `#1A1915` | 星图画布 |
| `nightSurface` | `#24221C` | 星图顶栏与抽屉 |
| `nightTextPrimary` | `#EDE8DC` | 夜文字与空心节点 |
| `nightTextSecondary` | `#A39B8C` | 夜次要文字 |

## 禁止项

- 日常页出现青紫渐变、粒子、辉光、毛玻璃和阴影。
- 每类资产一种填色圆，或把统计、临期、未关联做成三张同等大卡。
- 横向长条分类作为主要筛选入口。
- 图谱靠彩色关系、粒子或光晕表达结构。
- 空状态、错误文案和按钮展示技术细节或情绪化比喻。
